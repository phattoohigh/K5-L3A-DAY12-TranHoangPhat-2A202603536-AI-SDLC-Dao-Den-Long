# Credits

- Gameplay, renderer and UI: original procedural implementation for this project.
- 3D geometry: generated at runtime from primitive WebGL meshes; no external models or textures.
- Sound and music: synthesized at runtime with the browser Web Audio API; no external audio files.
- Fonts: macOS/Linux system serif and sans-serif fallbacks; no downloaded font assets or network font dependency.
- Code runtime: Node.js built-ins and browser WebGL/Web Audio APIs.
